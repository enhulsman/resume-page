## Stack Choices

Astro over Next or Remix because this site has no client-side app state: pages are static HTML with small scripts where interactivity demands it. The drawings are hand-written, ANNA's section is an orthographic canvas renderer of about 670 lines and the project details are inline SVG that plot themselves in, so the site ships no animation library and no CSS framework (about 87 KB of JavaScript in total). Every drawing has a still version for `prefers-reduced-motion`. The contact form runs server-side on Cloudflare Workers with the Resend API: no separate backend, no CORS proxy, just an edge function co-deployed with the static assets.

## The Terminal

On the homepage's first sheet, beside the photo, a terminal plays a typing animation as the page opens. After the animation finishes, the blinking cursor is real, and you can type into it. It implements 42 commands in vanilla TypeScript: filesystem navigation over a virtual filesystem (`ls`, `cd`, `cat resume`), unix staples (`grep`, `head`, `tail`, `wc`, `sort`, `env`), fun stuff (`cowsay`, `sl`, `matrix`, `neofetch`), and routing commands that actually navigate the site. Pipes work end-to-end (`cat resume | grep TypeScript | wc -l`), alongside tab completion, command history, and aliases. Mobile input uses a transparent overlay with touch gesture detection to separate taps from scrolls. Reliably opening the software keyboard across Android and iOS was the hardest part of the build.
