## The Idea

Most résumé sites look like résumé sites: a photo, a headline, a grid of skills. I wanted this one to stray from that and still hold everything a résumé should. The page is stone: warm grey, heavy type, nothing decorative. Glass only appears where something is really behind it: ANNA's conversation in Teams, Henk's chat in Signal, the homelab's own health check. Each project shows its own output instead of a screenshot, with a few soft lights far behind the glass. It started as a set of technical drawings; that version lives on in the git history.

## Built Like It Matters

A site like this only works if it's exact, so it's tested like something in production. Over a hundred browser tests check what a visitor would notice: that nothing scrolls sideways on a phone, that every window stays readable at every width, that the motion stops when your system asks for less of it.

## Stack Choices

Astro over Next or Remix because this site has no client-side app state: pages are static HTML with small scripts where interactivity demands it. The glass is one small WebGL shader, about 700 lines with its pane logic, that draws the ribbed and frosted panes and the soft lights behind them; with reduced motion, or on a device too slow for it, every pane holds still. The windows themselves are plain HTML, so the site ships no animation library and no CSS framework (about 86 KB of JavaScript in total). The contact form runs server-side on Cloudflare Workers with the Resend API: no separate backend, no CORS proxy, just an edge function co-deployed with the static assets.

## The Terminal

In the homepage's About section, beside my notes, a terminal in a frosted window types out a short session as it scrolls into view. After the animation finishes, the blinking cursor is real, and you can type into it. It implements 42 commands in vanilla TypeScript: filesystem navigation over a virtual filesystem (`ls`, `cd`, `cat resume`), unix staples (`grep`, `head`, `tail`, `wc`, `sort`, `env`), fun stuff (`cowsay`, `sl`, `matrix`, `neofetch`), and routing commands that actually navigate the site. Pipes work end-to-end (`cat resume | grep TypeScript | wc -l`), alongside tab completion, command history, and aliases. Mobile input uses a transparent overlay with touch gesture detection to separate taps from scrolls. Reliably opening the software keyboard across Android and iOS was the hardest part of the build.

## Two Things You Might Have Missed

Each link in the top bar glows in its own light when you point at it: the same four lights that sit behind the glass cards at the top of the homepage, one per page.

In the terminal, ask for a dark mode with `theme`. There is one theme: light.
