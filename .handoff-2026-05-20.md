## Key Decisions
- **Displacement + lerp (no velocity)** — replaced spring physics to eliminate oscillation. Dots can't overshoot.
- **Post-lerp direct offset for ripples** — the main lerp (8%/frame) is too slow for transient impulses. Ripple displacement bypasses the lerp and is applied directly to `dot.x/dot.y`.
- **Glow-only below fold** — user chose mode 2 (no repel below hero) to keep content sections calm.
- **Canvas 2D `fillStyle` for color normalization** — spec-guaranteed `#rrggbb` output regardless of CSS color format input.
