Project Data Discovery

MDX Auto-Discovery Pipeline
1
Write MDX File
Create /src/pages/projects/ProjectName.mdx with frontmatter metadata (title, description, date, tech, showcase flag)
2
Frontmatter Parsing
ProjectsShowcase.astro & /projects/index.astro use import.meta.glob() to discover all .mdx files
3
Filter & Sort
Filter by showcase: true flag. Sort by date descending. Extract title, description, tech tags, GitHub URL
4
Render Cards
ProjectCard.astro renders as spotlight cards with hover glow effect and link to full case study
5
Layout Applied
ProjectLayout.astro auto-applied via Astro config to all */projects/*.mdx files

Key Features & Architecture Decisions

🔄
Config-Driven Architecture
Single source of truth for projects, skills, and metadata. Changes to site.ts propagate across homepage showcase and SEO.
📝
MDX Auto-Discovery
Write a new .mdx file → automatically appears in listings. No route configuration needed. Astro config applies layout automatically.
🎬
Scroll-Triggered Animations
GSAP ScrollTrigger with [data-reveal] attributes. Fade-up on scroll. Respects prefers-reduced-motion.
✨
Spotlight Glow Effect
Project and ProjectCard components track mouse position with CSS custom properties for dynamic radial gradient glow on hover.
🌓
Theme Toggle
Dark/light mode stored in localStorage. Inline script prevents flash. CSS custom properties for semantic color names.
📱
Contact Form
Server-side form submission to Cloudflare Workers with Resend API. Client-side loading state, error/success messaging.
🎨
Responsive Design
Tailwind CSS with semantic spacing. Grid-based layouts. Mobile-first approach. Vite dev server on port 4321.
🔍
SEO-Optimized
Dynamic OG image. Custom metadata per page. Structured project descriptions. Keywords from config propagated to all pages.

Summary: How It All Fits Together

The site is built on a config-driven, zero-maintenance architecture:

  1. Single config file (site.ts) defines author, skills, featured projects, and SEO metadata
  2. Pages import config and render everything dynamically — no hardcoding project lists or skill badges
  3. MDX files in /projects are auto-discovered via import.meta.glob() — write frontmatter, get a page
  4. ProjectLayout.astro applied automatically to all project MDX files via Astro config
  5. Homepage showcase filters by showcase: true flag — same MDX drives both homepage cards and dedicated listing page
  6. All pages wrap with BaseLayout for consistent nav, footer, theme toggle, and animations
  7. Cloudflare Workers handle contact form server-side with Resend API integration

Result: Add a new project by creating one .mdx file. Update portfolio metadata once in site.ts. Everything else cascades automatically across homepage, project pages, SEO, and social shares.
